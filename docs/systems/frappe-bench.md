# Overview

The `frappe-bench` directory contains the core development setup for Frappe apps. It manages site configurations, applications, and python environments for the project.

# Apps

Configuration for apps to be installed is found in [apps-example.json](../../apps-example.json).

# Commands

To interact with the environment, use the standard `bench` CLI commands from within the `/workspace/development/frappe-bench` directory.
