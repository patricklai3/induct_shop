# Context Gathering Rule

Prior to beginning implementation of any new feature or modification, you MUST review the relevant documentation within the `docs/` directory of the `induct_shop` app to gather context, understand existing workflows, and align with current architectural patterns.

If necessary, you are also allowed to access files outside the workspace to collect information with regards to how other applications (e.g. ERPNext, Frappe HR) installed on the bench works.
